# Zaika Indian Restaurant Landing Page

A responsive landing page for Zaika Indian restaurant brand built with HTML5, CSS3, and JavaScript.

## 📋 Overview

This project is a fully responsive landing page for Zaika Indian Restaurant featuring:
- Hero section with captivating tagline and call-to-action buttons
- Menu section with categorized dishes and pricing
- About our chefs section showcasing culinary experts
- Testimonials carousel with customer reviews
- Booking/contact form with client-side validation
- Rich red and gold color scheme reflecting Indian restaurant aesthetics
- Fully responsive design (mobile-first approach)
- Accessibility features (WCAG 2.1 AA compliant)
- SEO optimized with meta tags and Open Graph support

## 🎨 Design & Features

### Color Scheme
- **Primary Red**: `#C41E3A` - Used for primary buttons, accents, and highlights
- **Secondary Gold**: `#FFB400` - Used for secondary buttons, hover effects, and decorative elements
- **Dark Background**: `#212121` - Main background color
- **Light Text**: `#F5F5F5` - Primary text color
- **Muted Text**: `#A9A9A9` - Secondary text and descriptions

### Typography
- **Headings**: Playfair Display (serif) - Elegant and traditional
- **Body Text**: Lato (sans-serif) - Clean and readable

### Sections
1. **Hero** - Full-width background with tagline and CTAs
2. **Menu** - Grid layout with dish categories, descriptions, and prices
3. **About Chefs** - Chef cards with images, names, and bios
4. **Testimonials** - Rotating carousel of customer reviews
5. **Booking/Contact** - Form with validation for table reservations
6. **Footer** - Contact information, quick links, and social media

### Interactive Elements
- Smooth scrolling navigation
- Active navigation link highlighting
- Form validation with real-time feedback
- Testimonial carousel with auto-rotation and manual controls
- Hover effects on buttons and menu items
- Responsive mobile menu (expandable)

## 🛠️ Technologies Used

- **HTML5** - Semantic markup for accessibility and SEO
- **CSS3** - Custom properties (variables), Flexbox, Grid, Animations
- **JavaScript** - Vanilla JS for interactivity and form validation
- **Google Fonts** - Playfair Display and Lato
- **Netlify** - Static site hosting

## 📱 Responsive Breakpoints

- **Mobile**: 320px and up
- **Tablet**: 768px and up  
- **Desktop**: 1024px and up
- **Large Desktop**: 1440px and up

## 🔧 Installation & Development

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/zaika-indian-restaurant-site.git
   ```

2. Open `index.html` in your browser to view the site locally

3. For development, you can modify the files in:
   - `/css/` - Stylesheets (style.css, responsive.css)
   - `/js/` - JavaScript files (script.js, form-validation.js, carousel.js)
   - `/assets/images/` - Image assets (add your own images)

## 🚀 Deployment

This site is configured for deployment on Netlify:

1. Push to GitHub
2. Connect your repository to Netlify
3. Set build command to: (leave empty)
4. Set publish directory to: `/`
5. Click "Deploy Site"

The site will automatically deploy when changes are pushed to the main branch.
